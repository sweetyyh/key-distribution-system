Product Description

Steam Gift Cards work just like a gift certificate, which can be redeemed on Steam for the purchase of games, software, wallet credit, and any other item you can purchase on Steam. This digital code provides immediate access to thousands of titles.

How to Redeem

  1. Launch the Steam client and log in
  2. Select Games > Redeem a Steam Wallet Code
  3. Enter the digital code provided after purchase
  4. Click Redeem to add funds to your wallet
